## Text: 

Effective to explain complicated findings or nuanced conclusions and describe their significance. Ideally, text is descriptive and concise and adapted to a lower reading level to that of the audience. Text should be formatted in a logical way. 

## Tables: 
Can be used to present data concisely. Look up for particular values. But require further effort from the audience than graphs. Useful if precision required. Should have descriptive titles and headers to render the table easy to read. Same level of precision of value should given to all number (same position of decimal points). 

## Graphs: 
Make patterns and outliers visible. Support rapid comparisons across values. How to select appropriate types of graphs depending on the case is important. In the additional ressources of this course, some readings provide recommendations on the graph types and applicabilities/adaptability. 

It is generally preferable to adopt a few types of graphs. It is best to use the most ideal type of graph and continue to present throughout the report where needed. This approach helps with consistency and accessibility of the report. 

Recommendations: 
- Do not use too many features 
- Each feature should highlight a key element of the take-away messages 
- Include explanatory text where needed 


## Maps 
Impactful with all types of audiences. Generally display one variable at a time and often use thresholds to colour areas. 

Considerations: 
- Note where data is not available and contested border areas. 
- Comparing between maps is not recommended as it is a tedious exercise. 

## Interactive data visuals 
Present large amount of data in an approachable and modifiable format. Make it possible to drill through various levels of data to create a narrow view focus. The use of interactive data visuals requires the audience to have digital literacy and access. For more info on best practices to develop interactive visual, can check the additional ressources of this module. 

**A piece of advise**: 
There are advantages to applying different presentation approaches. To best exploit a combination of approaches, we must ensure that they complement each other, rather than repeating key messages in different formats.
